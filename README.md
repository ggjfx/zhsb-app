# YH英语通 · 网页版（PWA App）

英语学习助手：分级背单词（小学/初中/高中/专升本·高频/中频/低频/四级/六级）、遗忘曲线复习、阅读/完形模拟练习、测验、错题本、统计。

支持**安装为 App**：手机主屏图标、全屏打开、离线可用；电脑浏览器也能「安装为应用」。

## 怎么用

### 方式一：直接双击（最简单）
双击 `index.html` 即可用（Chrome/Edge）。此方式功能完整，但不能离线缓存、不能装成 App。

### 方式二：本地服务器（推荐，支持 PWA 安装/离线）
双击 `start.bat` → 自动打开 http://localhost:8080
（或手动：`node server.js`，然后浏览器访问 http://localhost:8080）

### 方式三：部署到线上（手机也能安装）
需要把本文件夹放到 GitHub Pages 等 HTTPS 站点上（比如你的博客仓库）。
⚠️ 按规矩：部署前先给你预览，你审核说「发布」才发。

## 安装为 App

- **Android**：Chrome/Edge 打开 → 菜单「添加到主屏幕」
- **iPhone**：Safari 打开 → 分享按钮 →「添加到主屏幕」
- **Windows**：Edge/Chrome 打开 → 地址栏右侧安装图标 / 菜单「安装应用」

## 功能

| 页签 | 功能 |
| --- | --- |
| 学习 | 按级别背单词；学习/复习双模式；遗忘曲线 1/2/4/7/15/30 天自动排复习 |
| 练习 | 阅读理解 3 篇 + 完形填空 2 篇（原创模拟题，做错进错题本） |
| 测验 | 词汇 70% + 语法 30%，可按全部/未掌握/级别出题，即时解析 |
| 错题 | 单词/语法/阅读/完形错题自动收录，单词语法错题可重做 |
| 统计 | 打卡、待复习、已学/已掌握、答题数、正确率、今日记录 |
| 设置 | 导出/导入进度（JSON）、导入单词表（CSV，可带级别）、重置 |

## 数据

- 250 个内置单词四级分布：基础 81 / 初级 99 / 中级 38 / 高级 32；语法 30 题
- 数据存浏览器本地（localStorage），不上传；定期「设置 → 导出进度」备份
- 导入单词表：`单词,音标,词性,释义,例句,例句翻译,级别`（Tab/逗号分隔，级别 1~4 或 基础/初级/中级/高级）

## 开发

数据与小程序版共用 `../zhsb-data` 数据源，修改后运行 `node ../zhsb-data/build.js` 重新生成两边的 `data/data.js`；图标用 `node ../zhsb-data/gen-icons.js` 重新生成。
